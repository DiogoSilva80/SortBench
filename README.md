Autor: Diogo Silva (Nº Estudante: 2024199827)   Descrição do ProjetoEste projeto visa a resolução rigorosa de um problema de ordenação em larga escala, focado no processamento de conjuntos gerados aleatoriamente de registos de antigos estudantes. O sistema é capaz de processar até 1.000.000 de entradas.   Cada registo é gerido através de uma estrutura (struct) que armazena três atributos principais:   Número de identificação (id).   Tipo de curso (tipo_curso), limitado a valores de 0 a 2.   Classificação final (nota), limitada ao intervalo de 10 a 20.   O objetivo consiste em produzir três listagens com diferentes critérios de ordenação e rigorosas exigências de estabilidade, comparando a complexidade assintótica e o desempenho prático de vários métodos.   Algoritmos de Ordenação ImplementadosPara a avaliação experimental, o ficheiro main.cpp implementa quatro algoritmos distintos:   Bubble Sort: Implementação clássica com a adição de uma flag booleana de paragem antecipada. Se for detetada uma travessia sem permutações, o algoritmo aborta o processo, permitindo que o melhor caso convirja para $O(n)$.   Merge Sort: Solução de divisão e conquista de referência com tempo de execução de $O(n \log n)$. A lógica foi desenhada para priorizar a estabilidade estrutural, dando precedência ao elemento do sub-vetor esquerdo em caso de igualdade de chaves.   Heap Sort: Algoritmo estritamente in-place com complexidade espacial de $O(1)$ e complexidade temporal de $O(n \log n)$. Devido à manipulação de posições distantes, é inerentemente instável e inadequado para listagens que exigem manutenção rigorosa da ordem prévia.   Counting Sort (Otimizado): Algoritmo implementado para as Listagens 2 e 3 que substitui comparações por indexação direta num histograma. Opera num limite temporal linear de $O(n+k)$ (onde k é a amplitude das chaves) e assegura estabilidade matemática através de uma travessia invertida do array original no momento do preenchimento final.   Geração Estocástica de DadosA geração das massas de teste evita alocações a priori e baseia-se num motor estatístico rigoroso recorrendo à biblioteca <random> (mt19937):   Multiplicidade de Cursos: Implementou-se um modelo de injeção em tempo real onde 5% dos estudantes possuem registos de múltiplos cursos (entre 2 a 3 cursos por ID replicado).   Classificações: As notas são geradas recorrendo a uma distribuição binomial exata transladada. O sistema realiza uma simulação com 10 ensaios de Bernoulli ($B(10, 1/3)$) e soma uma constante de 10 unidades para garantir resultados entre 10 e 20 com assimetria positiva.   Desempenho e Resultados EmpíricosOs testes processam conjuntos variando entre $10^3$ e $10^6$ registos, distribuídos por três graus de ordenação inicial (Tipo A, Tipo B e Tipo C).   O Bubble Sort demonstrou a impraticabilidade dos limites quadráticos para larga escala, mas provou ser o mais rápido (comportamento linear) nos conjuntos previamente ordenados devido à heurística de paragem.   O Merge Sort demonstrou robustez mantendo-se sempre na proporção log-linear $O(n \log n)$ independentemente da disposição inicial dos dados, estabilizando na ordem dos 250 a 350 milissegundos para 1 milhão de registos.   A otimização extrema com Counting Sort mitigou o overhead das comparações e ordenou 1.000.000 de registos em cerca de 8.5 ms, uma redução temporal na ordem dos 97%.
